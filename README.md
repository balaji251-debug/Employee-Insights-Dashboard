# Employee Insights Dashboard

## Project Overview

Employee Insights Dashboard is a Data Analytics project created to analyze employee data and generate useful insights about employee distribution, salary, departments, cities, and gender.

## Objective

The objective of this project is to clean, analyze, and visualize employee data using Excel, MySQL, and Power BI.

## Dataset

The dataset contains 500 employee records with the following columns:

- Employee_ID
- Name
- Department
- Gender
- City
- Salary
- Joining_Date

## Tools Used

- Excel
- MySQL
- Power BI

## Project Workflow

### 1. Excel
- Cleaned and prepared the employee dataset.
- Checked the data for formatting and consistency.
- Prepared the data for database analysis.

### 2. MySQL
- Created the `employee_project` database.
- Created the `employees` table.
- Loaded 500 employee records.
- Converted `Joining_Date` into DATE format.
- Performed SQL analysis using aggregation and GROUP BY queries.

### 3. Power BI
- Connected MySQL data to Power BI.
- Created KPI cards for:
  - Total Employees
  - Average Salary
  - Total Departments
  - Total Cities
- Created visualizations for:
  - Department-wise Employee Count
  - Average Salary by Department
  - City-wise Employee Count
  - Gender-wise Employee Count

## Key Insights

- Analyzed employee distribution across departments.
- Compared average salaries across departments.
- Analyzed employee distribution across different cities.
- Studied gender-wise employee distribution.
- Created a dashboard for quick and easy analysis.

## Project Files

- `Employee_Data.csv` – Employee dataset
- `SQL_Queries.sql` – SQL queries used for analysis
- `Employee_Insights_Dashboard.pbix` – Power BI dashboard

## Conclusion

This project demonstrates the use of Excel, MySQL, and Power BI to perform data cleaning, SQL analysis, data visualization, and dashboard creation.
